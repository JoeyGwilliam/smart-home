# Kiosk viewer (web)

A React + TypeScript viewer for the reminders API, replacing `apps/kiosk_viewer_python`.

The app calls the API under `/api` on its own origin. In development Vite forwards those calls to `localhost:8000`
(see `vite.config.ts`); in Docker, nginx forwards them to the `reminders-api` service (see `nginx.conf`).

## Development

From this directory, with the reminders API running on port 8000:

    npm install
    npm run dev

## Checks

    npm test        # runs the tests in tests/, which mirrors src/
    npm run build   # type-checks, then builds into dist/
    npm run lint

Due times are shown in the time zone of the device displaying the page, so set the kiosk's clock and time zone
correctly. `src/components/ui/` holds components generated by shadcn/ui (`npx shadcn@latest add <name>`); they are
ours to restyle.
